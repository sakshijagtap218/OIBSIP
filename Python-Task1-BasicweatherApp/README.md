# Basic Weather App

## Description
A basic weather application developed using Python as part of the Oasis Infobyte internship.

## Features
- Search weather by city
- Display current weather information
- Display temperature
- Display weather conditions
- Simple and user-friendly interface

## Technologies Used
- Python
- Weather API

## How to Run
1. Install Python.
2. Install the required libraries.
3. Add the API key.
4. Run the Python application.
